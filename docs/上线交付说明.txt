三 上线方式
这是纯静态网站，无需安装依赖或执行构建。将 website 文件夹内的内容部署到网站根目录，保持 zh/index.html 路径。
可部署至企业现有静态托管、Nginx、对象存储静态网站或 CDN 托管。
默认首页设为 index.html，并支持 /zh/ 目录首页。不要把所有路径强制重写为英文首页。
中英文切换采用根路径 / 和 /zh/，适合独立域名根目录部署。如部署到子目录，需同步修改两页的语言切换路径。
中文、英文页面均使用 UTF-8 编码。
域名解析、HTTPS 证书和企业托管账号由上线同事配置。
本地预览：进入 website 目录后运行 python3 -m http.server 8080，通过 http://localhost:8080/ 查看英文，通过 http://localhost:8080/zh/ 查看中文。建议通过 HTTP 预览，直接双击 HTML 时根路径资源及语言切换可能无法正常加载。
正式域名尚未在本包中设定，前端同事需向负责人确认。
