三 上线方式
这是纯静态网站，无需安装依赖或执行构建。将 website 文件夹内的内容部署到网站根目录，保持 zh/index.html 路径。
可部署至企业现有静态托管、Nginx、对象存储静态网站或 CDN 托管。
默认首页设为 index.html，并支持 /zh/ 目录首页。不要把所有路径强制重写为英文首页。
中英文切换采用根路径 / 和 /zh/，适合独立域名根目录部署。如部署到子目录，需同步修改两页的语言切换路径。
中文、英文页面均使用 UTF-8 编码。
域名解析、HTTPS 证书和企业托管账号由上线同事配置。

五 维护说明
CSS 内嵌于每页的 style 标签中；无外部图片、字体服务、第三方 JavaScript 依赖、数据库或服务端。页面含原生 JavaScript，用于滚动渐入动效。
目前两种语言分别维护，调整共用样式或结构时需同步两份 HTML。
部分样式以追加规则形式覆盖早期规则，维护时可重构合并，但需核对最终显示效果。
如迁移到 React、Vue 或企业组件体系，可按 header、hero、about、business、lifecycle、future、contact、footer 拆分；无需改变已确认文案。
文件中的系统字体栈会随设备选择可用字体。

首屏背景网格包含 10 秒循环网格流动及 16 秒单程透视变化；系统开启减少动态效果时关闭动画。

六 上线验收
核对桌面及手机显示，特别是英文长标题换行、导航和页脚对齐。
检查默认 EN、CN / EN 往返切换和各导航锚点。
点击 Contact Us / 联系我们，确认收件人为指定邮箱。
确认 HTTPS、域名根目录及 /zh/ 均能正常打开；刷新中文页面后仍保留中文。
检查页面标题、描述、语言标记和无重复文案。
当前已做源码结构、文案和链接检查；本次交付未完成最终浏览器视觉验收，请上线前在目标环境检查。
如需搜索引擎收录，上线同事需基于最终域名配置 canonical、hreflang、robots.txt 和 sitemap.xml。
本包不含原托管平台的项目配置、账号信息或 Git 历史，可独立部署。
